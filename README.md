
# CampusIQ – Student Data Analytics & Visualization Platform

A comprehensive data analytics and visualization platform that helps educational institutions analyze student academic data, gender distribution, and placement statistics using Business Intelligence tools.

---

## 🎯 Project Overview

**Project Title:** CampusIQ – Student Data Analytics & Visualization Platform.

**Course:** B.Tech 3-2 Semester E2E Mini Project.

Technology Stack:

Microsoft Excel

Microsoft Power BI

Purpose:
To analyze and visualize student academic and placement data using Business Intelligence tools to support data-driven institutional decision making.
