⚙️ Project Workflow

1️⃣ Data Collection

    Collect raw student data including: 
  -> Student registration details
  -> Academic performance (SSC, Inter, Graduation marks) 
  -> Entrance exam ranks
  -> Placement records
  -> Department information

2️⃣ Data Cleaning (Python)

  Data preprocessing is performed using Python and Pandas:
  -> Import datasets
  -> Handle missing values
  -> Remove duplicate records
  -> Standardize data formats
  -> Transform columns and create features
  -> Export cleaned dataset to CSV/Excel

3️⃣ Data Integration in Power BI

  -> Import cleaned dataset into Power BI
  -> Use Power Query Editor for transformations
  ->Combine datasets from multiple years (2019–2024)

4️⃣ Data Modeling & KPI Creation

  Create calculated metrics using DAX:
  -> Total Admissions
  -> Total Placements
  -> Placement Rate
  -> Average Academic Scores
  -> Department-wise analysis 
  -> Higher studies analysis

5️⃣ Dashboard Development

Interactive dashboard features include:
-> Admissions trend analysis
-> Department-wise placement performance
-> Academic performance comparison
-> Placement distribution visualization
-> KPI summary cards

Visualization types used:
-> Line charts
-> Clustered column charts
-> Donut charts
-> KPI cards
-> Slicers and filters

6️⃣ Insights & Reporting

The dashboard helps identify:
-> Admission trends over multiple years
-> Departments with higher placement rates
-> Academic performance patterns
-> Placement vs unemployment distribution
-> Future admission trends using forecasting
-> These insights support strategic decision-making for educational institutions.

🛠️ Tools & Technologies

Python (Pandas) – Data cleaning and preprocessing
Excel – Data structuring and organization
Power BI – Data visualization and dashboard development
DAX – KPI calculations and analytical measures

🎯 Project Outcome
The CampusIQ dashboard provides a centralized platform to monitor student analytics and placement trends. 
It simplifies complex datasets into interactive visual insights, helping institutions improve academic planning and placement strategies.
